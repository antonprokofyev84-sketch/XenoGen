# Изображения

## Подготовка

| Ассет   | Исходник                                                                                |
| ------- | --------------------------------------------------------------------------------------- |
| Портрет | Отдельный квадрат головы и плеч, экспорт 200×200; лицо по центру, глаза в верхней трети |
| Фигура  | Полный рост с прозрачным фоном, вся голова, руки и стопы внутри холста                  |
| Фон     | 16:9, от 1600×900                                                                       |

Фигуры разных персонажей готовятся в общем масштабе тела и сохраняют разницу
физического роста. Середина между макушкой и подошвами совпадает с вертикальным
центром холста; фигура центрируется и по горизонтали. Низкий персонаж имеет больше
пустого пространства сверху и снизу. Шлем, причёска, оружие и плащ сохраняют масштаб тела.

Размеры изменяются пропорционально. Прозрачные поля являются частью нормализации:
обрезание с последующим заполнением всей высоты уничтожает разницу роста.
Портрет готовится самостоятельно, а не вырезается из фигуры в runtime.
На экране персонажа полный холст показывается через contain с центрированием.
[POI UI](poi-ui-design.md#композиция) задаёт увеличенный показ с обрезанием снизу.
Точный формат общего холста и пиксельная сетка роста — задача в [backlog](ideas.md).
Это правило подготовки новых файлов: UI не вычисляет рост NPC и не нормализует
имеющиеся изображения автоматически. Один `contain` не сохраняет разницу роста,
если каждый исходник заранее обрезан и заполнен телом до краёв.

## Хранение и загрузка

Новые игровые картинки размещаются в `src/assets/`:

```text
npcs/<npcId>/full-body.webp
npcs/<npcId>/portrait.webp
backgrounds/<locationId>/<scene>.webp
```

PNG также поддерживается; на один вид изображения NPC выбирается один файл.
Крупные исходники и промежуточные генерации сохраняются под отдельными именами,
которые не попадают в runtime resolver.

Фоны подключаются статическим import, NPC — glob в `src/systems/npc/npcImageResolver.ts`.
Vite формирует URL с хешем и production base. `public/` подходит для файлов
с постоянным внешним URL; обращение из кода учитывает `import.meta.env.BASE_URL`.

## Fallback

`src/assets/characters/fallbacks/male-185-v2.png` и `female-170-v2.png` —
обезличенные тёмные фигуры в простой одежде с мягким объёмом и тёплым контурным светом.
Они изображают примерно 185 и 170 см в общем масштабе.
`InitialNpc.gender` выбирает вариант. У legacy `Character` без gender используется мужской.
Resolver подставляет fallback при отсутствии фигуры; ошибка загрузки также переключает
UI на него с защитой от повторного onError. Для отсутствующего портрета применяется иконка.

Фактические размеры и промпты fallback хранятся [рядом с файлами](../../src/assets/characters/fallbacks/README.md).
Происхождение демонстрационных ассетов — [POI demo art](../../src/assets/poi-demo-assets.md).
