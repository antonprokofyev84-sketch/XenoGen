# POI UI

## Композиция

Общая оболочка POI и карты — `GameScene`, `GameHud`, `GameSystemMenu` из
`src/components/GameHud/`. Сцена 1600×900 CSS px, рамка 1 px, без масштабирования.
Большое окно центрирует её, маленькое даёт прокрутку внешнего viewport.

| Элемент             | Геометрия                                                         |
| ------------------- | ----------------------------------------------------------------- |
| Панель действий     | x=440, bottom=24, 800×224 px                                      |
| Фигура слева        | x=0, y=70, контейнер шириной 440 px; полный холст высотой 1000 px |
| HUD справа сверху   | Ширина 272 px, top/right=24                                       |
| Системное меню      | 272×96 px, bottom/right=24; четыре кнопки 56×56 в ряд             |
| Панель NPC над меню | 272×116 px, bottom=132; промежуток до меню 12 px                  |
| Карточка NPC        | 56×76 px, портрет 56×56                                           |

Фон заполняет сцену через cover. Холст фигуры центрируется по горизонтали,
низ обрезается краем сцены; у трактирщика — примерно на середине икр.
Изображение не перехватывает ввод. Подготовка ассетов — [отдельный стандарт](visual-assets.md).

Портреты и меню вместе занимают ту же высоту, что панель действий. В панели четыре
карточки на странице, occupants подряд, пустые рамки в конце. Полное имя доступно
через tooltip; подпись однострочная с ellipsis. Выбранный NPC подсвечен.
Портреты сохраняются в разговоре и внутренних Frames; выбор доступен в root после чтения.

## Actions и навигация

Панель сохраняет геометрию между POI и разговором. Actions выводятся в две колонки,
до шести на странице, с Previous/Next. Порядок задаёт runtime resolver.
Длинные подписи сохраняются целиком; переполнение области обрабатывается
прокруткой, а не обрезанием контента под фиксированный макет.
Категория определяет иконку, денежный cost показывается рядом с label;
требования и причины disabled — в tooltip.
При построении варианта один resolved cost используется для preview и проверки
ресурсов. В начале попытки executor разрешает её стоимость отдельно:
показанная цена не является сохранённым платежом.
Время и вероятность выполнения Action скрыты и на кнопке, и в подсказке.
Скрытые conditions не раскрываются через подсказку: она объясняет доступность
показанного выбора, а не рассказывает об ещё неизвестных возможностях.

Заголовок разговора показывает имя и отличающуюся роль; внутреннего Frame без NPC — его title.
В POI root название остаётся в HUD. History и Leave/End talk расположены рядом.
Выход показывается по runtime-навигации: возврат из NPC root либо родительский переход.
Внутренний Frame ведёт игрока своими Actions.

Под HUD расположен прямой список доступных дочерних переходов. Disabled-вход
показывает причину; во время чтения навигация и портреты disabled.
Длинный список прокручивается в доступной высоте; количество переходов не
ограничивается демонстрационным числом из макета.

## Текст и History

Текущая порция целиком заменяет Actions. Длинный текст прокручивается внутри панели.
После анимации Continue срабатывает кликом по свободной текстовой области или пробелом.
Выделение текста, перетаскивание, повтор клавиши и второй клик двойного нажатия
не подтверждают порцию и не запускают появившийся Action.

History доступна во время чтения и показывает подтверждённые порции. Она открывается
модальным окном с затемнением и закрывается кнопкой, Escape или кликом снаружи.
Ввод открытого модального окна не передаётся сцене под ним; торговая модалка
также приостанавливает обработчик Continue. Просмотр истории не повторяет
checks/effects и не меняет текущую порцию.
Модель данных и переход к следующей порции заданы в
[runtime](interaction-runtime-state-design.md#текст-и-история).

## Текст интерфейса

Интерфейс и демонстрационный контент используют английский язык.
UI-подписи и шаблоны находятся в `src/locales/en.json`, разрешение — через `t`
из `src/systems/text/i18n.ts`. Используется ядро i18next с bundled `en`:
параметры `{{name}}`, plural forms `_one`/`_other` с `count`.
Текст выводится через React как текст, а не HTML.

Domain resolver возвращает данные причины недоступности, например тип ресурса,
`available`, `required`, `itemId`; `systems/text/interactionText.ts` превращает
их в подпись. Художественный контент использует
[LocalizedText и narrative](frame-initial-data-design.md#narrative).

## HUD и системное меню

HUD показывает название, родителя, статус доступа, день/часы и четыре региональных
уровня иконками с одной цифрой. До посещения клетки уровни отображаются как «—».
Свёрнутый HUD оставляет название, день, часы и строку expedition points;
`ui.isLocationHudCollapsed` сохраняется между экранами. Строка expedition points
использует «—»; проектирование ресурса находится в [backlog](ideas.md).

Inventory возвращает на вызвавший экран. Map сохраняет interaction; пока партия
внутри POI, карта работает в режиме просмотра с Return to location. Party/Settings
показываются disabled. На карте справа выводятся обнаруженные POI выбранной клетки
с информацией при наведении и фокусе; команды региона относятся к выбранной клетке.

## Оформление

Палитра и панели — `_theme.scss`, кнопки — `_button.scss`, иконки — `GameIcon.tsx`.
Панели используют border 1 px, `corner-shape: bevel`, полосатый полупрозрачный фон
и тёплое свечение. Actions, навигация и History используют общий `game-button`
высотой от 44 px. Заголовок — 21 px, narrative — 18 px, Actions — 17 px,
вторичный текст — 14 px.

`GameTooltip` использует Floating UI и portal с `poiTheme`; появляется при hover/focus,
закрывается по Escape и связывается с контролом через `aria-describedby`.
