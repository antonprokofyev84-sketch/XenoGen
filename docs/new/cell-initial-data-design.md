# Клетки карты

Формат: [cellContent.types.ts](../../src/types/cellContent.types.ts),
runtime-узлы: [worldNode.types.ts](../../src/types/worldNode.types.ts).
Реестр: `src/data/initial/cells.ts`; ID helpers — `src/systems/world/cellId.ts`.

## Initial-данные

Клетка содержит `id` и `details`: terrain, полный объект региональных параметров
и optional начальное состояние посещений и разведки. ID имеет вид `{col}-{row}`,
координаты — неотрицательные целые.
Initial-набор описывает полную фиксированную сетку с уникальными Cell IDs.
Например, `3-1` означает col=3, row=1. Координаты выводятся из ID,
а не задаются вторым независимым источником данных.

Инициализатор добавляет `parentId: null`, `rootCellId: id`, координаты из ID
и `childPoiIds` непосредственных дочерних POI. Topology guards определяют клетку
по `parentId`. Все клетки фиксированной карты видимы.
Нормализация применяет defaults, затем явное initial-состояние, затем координаты
из ID. Поэтому автор может задать уже посещённую или разведанную стартовую клетку,
а runtime читает обязательные числовые поля без повторной подстановки defaults.

Пример записи; параметры региона задаются полным объектом:

```ts
{
  id: '3-1',
  details: {
    terrain: 'forest',
    regionParameters: { prosperity: 300, techLevel: 200, contamination: 20, threat: 100 },
    explorationLevel: 40,
    explorationDaysLeft: 3,
  },
}
```

## Посещения и разведка

| Поле                  | Начальное значение | Смысл                               |
| --------------------- | ------------------ | ----------------------------------- |
| `visitedTimes`        | 0                  | Число дней с завершённым посещением |
| `lastTimeVisited`     | `null`             | Время последнего выхода             |
| `explorationLevel`    | 0                  | Достигнутый уровень разведки        |
| `explorationDaysLeft` | 0                  | Дни актуальности разведданных       |

`explorationDaysLeft > 0` означает актуальную разведку, `0` — устаревшую,
`null` — бессрочную. При истечении остаётся `0`; сама клетка сохраняется.
При нуле `visitedTimes === 0` означает неисследованную клетку, положительный
счётчик — посещённую с устаревшими данными. Истёкшая дистанционная разведка без
посещения также возвращается к состоянию неисследованной клетки.
Разведка раскрывает POI, чей `explorationThreshold` достигнут. Обнаруженный POI
сохраняет `isDiscovered` после истечения разведданных клетки.
Текущий `exploreCell` проверяет непосредственно дочерние POI клетки.
Дневное уменьшение разведки использует общую фазу мировых счётчиков;
истечение сохраняет `explorationLevel` и историю посещений, меняя актуальность данных.

Учёт выходов общий с [POI](poi-initial-data-design.md#посещения).

[Региональные параметры](RegionParameters.md) определяют значения `details.regionParameters`.
[POI](poi-initial-data-design.md) определяют размещённые в клетке объекты.
